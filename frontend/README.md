# Frontend

Screens are added here by each task (plain HTML forms and tables are enough).
They call the backend API: http://127.0.0.1:8000/docs lists every endpoint.


## T1 screens

Start the backend and open http://127.0.0.1:8000/ui/
(`login.html`, `register.html`, `submit.html`, `mine.html`, `account.html`).

The submit form lists only tracks whose deadline is still ahead. With an empty
database, load demo tracks first (see the top of `db/seed/demo_t1.sql`).
